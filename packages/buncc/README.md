# @yolo/buncc

Bun C Compiler: a `cc`/`c++`/`ar`/`link` driver and toolchain orchestrator for clang, MSVC via xwin, MinGW, MSYS2, CMake, GN, vcpkg, uv, just, Rust, WebAssembly and .NET. Run with Bun.

```sh
bun add -g @yolo/buncc
buncc --help
```

Toolchains are downloaded on demand from their upstream publishers; none are bundled in this package.

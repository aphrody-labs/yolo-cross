# @yolo/bun-android

Android Gradle and JVM interoperability helpers for Bun cross-compilation
workflows. The package exposes Gradle, JVM, Android target types, and an
explicit Bun plugin through its package exports. Its `bun-android` executable
is retained for compatibility.

Android JNI class names, exported native symbols, and existing filesystem and
environment identifiers remain unchanged for compatibility with existing
Android projects and native artifacts.
